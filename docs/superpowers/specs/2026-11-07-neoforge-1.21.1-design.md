# NeoForge 1.21.1 支援設計

作者：dishanhai。用戶於 2026-11-07 確定目標為 1.21.1，同步升級 SH-Better-UI。

兩個專案各新增 `neoforge/` 獨立 Gradle 建置，維持根目錄 Forge 1.20.1 建置與既有產物。各平台只覆寫存在 API 差異的來源，共用純邏輯、語言與圖片；不以執行時反射混合兩個 Minecraft 版本。NeoForge 產物名稱包含平台及 Minecraft 版本。

Nexus 保留方塊 ID、每秒提交、隊伍驗證、真實 AE 扣料、獎勵待交付緩衝及去重語義。使用 NeoForge payload API；物品保存改接 1.21.1 data components，採掘保存用戶資料、創造複製不帶 UUID 與待交付物。FTBQ 與 AE2 API 以實際下載的 1.21.1 jar 驗證。Jade 為可選整合。

SH-Better-UI 保留對 Nexus 使用的公開玻璃／模糊／動效 API，獨立發行 NeoForge jar，改接 NeoForge 客戶端事件與渲染生命週期；Kotlin runtime 採該平台對應外部前置。LDLib 接口只在存在相容依賴時建置，原生 Screen 不得因 LDLib 缺失而載入失敗。

驗收：兩庫 NeoForge 編譯、單元測試、Nexus 專用伺服器 GameTest、jar 內容與依賴隔離檢查；根目錄 Forge 建置回歸。客戶端玻璃外觀、shader 相容性與 GUI scale 實機驗收另列，不將編譯或伺服器測試當作視覺證明。不部署至現有整合包，不提交或推送 Git。
