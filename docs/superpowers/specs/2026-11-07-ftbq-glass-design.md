# FTBQ 可配置玻璃覆盖设计

作者：dishanhai。用户已选择“主题覆盖＋局部绘制适配”。

在 FTB Quest Nexus 中新增纯客户端外观覆盖。Forge 1.20.1 和 NeoForge 1.21.1 各自适配平台配置与渲染 API，复用外置 SH-Better-UI 的透明玻璃配色、几何和实时模糊，不修改或嵌入依赖实现。

配置文件 `ftb_quest_nexus-client.toml`，分组 `ftbqUi`：`mode = "ORIGINAL"`（原版默认，可选 `GLASS`）；`opacity = 1.0`（0..1，乘以玻璃填充／边框原始 alpha，0 跳过面层；非零时库内细高光及 tooltip 使用预设材质）；`blurRadius = 8`（0..16 整数 GUI 单位，0 关闭模糊）。每个界面打开时捕获配置，关闭重开后应用新值；子对话框沿用所属任务界面的配置。

覆盖主题的底板、按钮、槽位、输入框、滚动条、复选框、页签、右键菜单和弹窗。局部适配直接读取 ThemeProperties 的主画面边栏、任务详情及版本特有章节背景。保留任务图标、任务节点形状和状态色、自定义章节图片、依赖连线、原有文本与编辑交互，不更改服务端业务或协议。自定义根背景图片保留，原版方格根背景由玻璃替换。

作用域限定 FTBQ 自有界面及从其打开的 FTB Library 配置／选择对话框；其他模组使用 FTB Library 的界面保持原主题。ORIGINAL 不修改绘制、tooltip 或模糊白名单行为。模糊不可用时保留透明材质，根底板每帧采样一次，避免每个按钮重复后处理。

验收分为纯逻辑单测、真实依赖 Mixin 目标核验、双平台构建／产物隔离和专用服务器 GameTest；客户端视觉、拖曳缩放、模态点击、编辑、提交／领奖、不同 GUI 缩放及其他模组兼容必须单独实机验收。
