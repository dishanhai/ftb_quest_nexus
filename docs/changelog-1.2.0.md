# 🎉 FTB Quest Nexus v1.2.0

[English](#english) · [简体中文](#简体中文)

## English

This update adds a Minecraft 26.1.2 build and more control over quest automation and appearance.

### ✨ What's new

- **Minecraft 26.1.2:** Added a separate NeoForge build using Java 25.
- **Independent block themes:** Choose separate SH-Better-UI themes for the submitter and checker, follow the global theme, or use resource-pack themes.
- **In-game settings:** Configure quest-book appearance, the submitter entry in quest details, and search suggestions from the mod configuration screen.
- **Server controls:** Use `/ftbqn config` to manage automation rules and defaults for newly placed submitters.

<details>
<summary>📦 Platforms and installation</summary>

| Minecraft | Loader | Java |
| --- | --- | --- |
| 1.20.1 | Forge | 21 |
| 1.21.1 | NeoForge | 21 |
| 26.1.2 | NeoForge | 25 |

Install the matching build and its required dependencies, including **AE2**, **FTB Quests**, **FTB Teams**, **FTB Library**, **GuideME**, **SH-Better-UI**, and the appropriate **Kotlin for Forge** runtime. The 1.20.1 and 1.21.1 FTB mods also need **Architectury API**. The 26.1.2 build uses SH-Better-UI `1.0.7-alpha.8` and Kotlin for Forge `6.2.0`.

For multiplayer, update the server and clients together. Multiplayer and old-world testing for 26.1.2 is still pending.

</details>

## 简体中文

本次更新新增 Minecraft 26.1.2 构建，并提供更多任务自动化与界面外观设置。

### ✨ 更新内容

- **Minecraft 26.1.2：** 新增独立的 NeoForge 构建，使用 Java 25。
- **方块独立主题：** 可分别为提交器和检查器选择 SH-Better-UI 主题、跟随全局主题或使用资源包主题。
- **游戏内设置：** 在模组配置界面调整任务书外观、任务详情中的提交器入口和搜索补全。
- **服务端控制：** 使用 `/ftbqn config` 管理自动化规则，以及新放置提交器的默认设置。
